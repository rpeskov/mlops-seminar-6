## До занятия

1. Установить Docker Desktop и проверить: `docker run --rm hello-world`.
2. Установить Python 3.12.
3. Склонировать или скачать этот репозиторий.

## Порядок на занятии

```
python -m venv .venv
source .venv/bin/activate            # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
python train.py                      # -> model.bin

# заполнить TODO в app.py, затем:
uvicorn app:app --host 0.0.0.0 --port 8000
python test_requests.py              # во втором терминале

# заполнить TODO в Dockerfile, затем:

curl http://localhost:5000/v2/price-estimate/tags/list
```

## Как понять, что запущена заготовка, а не решение

`/ready` отвечает `null`, а `/predict` на любой запрос отвечает 422 с `extra_forbidden` на каждое поле. Так ведёт себя `app.py` с незаполненными `TODO`: у класса `Listing` нет полей, и при `extra="forbid"` все поля считаются лишними. Заполните `TODO 1` и дальше, или для проверки запустите решение: `uvicorn solution.app:app --host 0.0.0.0 --port 8000` из корня папки.

## Если что-то не работает

- Сервис запущен, но `curl` получает отказ соединения: проверьте `--host 0.0.0.0` в команде запуска и `-p 8000:8000` при запуске контейнера.
- `ModuleNotFoundError`: не активировано окружение, в приглашении нет `(.venv)`.
- `docker push` отвечает `denied`: в имени образа нет `localhost:5000/`.
- Mac, порт 5000 занят: используйте `-p 5001:5000` и `localhost:5001`.
- Образы не скачиваются: архив с образами `docker load -i images.tar` и папка `wheels/` для `pip install --no-index --find-links=wheels -r requirements.txt` лежат рядом с репозиторием.
